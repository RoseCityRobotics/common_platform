# RViz Sensor Visualization

This guide will show you how to use RViz to visualize sensor data from your robot, including LiDAR, cameras, and other sensors.

## Prerequisites

- VM set up with ROS2 Kilted Desktop installed (see [Installing VMs](installing_vms.md))
- VM connected to the discovery server
- Robot powered on and connected to the same network

## Launching RViz

From your VM terminal:

```bash
rviz2
```
